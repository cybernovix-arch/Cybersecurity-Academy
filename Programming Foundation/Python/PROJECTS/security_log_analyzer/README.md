# Security Log Analyzer

## Overview

The Security Log Analyzer is a beginner-level Python cybersecurity project developed as part of the Cybersecurity Academy Python Programming Foundation.

The project analyzes an authentication log file and identifies failed login attempts. It counts the total number of failed attempts, displays the results on the screen, and saves the analysis to a report file.

The project demonstrates basic Python programming concepts and introduces simple security log analysis.

---

## Project Objectives

The objectives of this project are to:

- Read data from a log file.
- Analyze log entries using Python.
- Identify failed login attempts.
- Count suspicious login events.
- Display a security analysis report.
- Save the report to a text file.
- Practice using Python functions and return values.
- Practice file handling.

### main.py

Contains the main Python program.

The program includes:

* `analyze_log()` — analyzes the authentication log.
* `display_report()` — displays the analysis results.
* `save_report()` — saves the results to `report.txt`.
* `main()` — controls the overall program flow.

### auth.log

Contains simulated authentication log entries.

The program searches the file for entries containing:

```text
Failed login
```

### report.txt

Contains the security analysis generated by the program.

This file is created automatically when the program runs.

### README.md

Contains documentation explaining the project, its purpose, structure, and usage.

## How to Run

Open a terminal in the project directory and run:

```bash
python main.py
```

The program will:

1. Read `auth.log`.
2. Find failed login attempts.
3. Count the failed attempts.
4. Display the results.
5. Create or update `report.txt`.
